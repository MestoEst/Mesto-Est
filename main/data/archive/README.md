# Архив, не источник приложения

- spots-satellite-original.geojson — неизменённый исходный GeoJSON из main b46b4cb, 734 спутниковых полигона. Геометрия с новым набором не сопоставляется. Обычный импорт отвергает этот формат.
- frontend-generator-e4e0875.js и frontend-streets-e4e0875.js — снимок генератора карты Ани и её подписей. Не подключаются в HTML. Сохранены только для воспроизведения однократного экспорта и проверки геометрии оформления.

Единственный контролируемый набор первоначальной загрузки: ../spots.geojson. При обычной работе карта загружает базу через API.
