# Место есть: фронтенд прототипа

Обычные HTML, CSS и JavaScript без сборки.

## Как посмотреть
- **Через VS Code:** правой кнопкой на `frontend/index.html`, затем **Open with Live Server** (или кнопка **Go Live** внизу справа). Библиотека карты Leaflet и плитки карты загружаются из интернета, нужен интернет.
- **Через Django:** `python manage.py runserver`, страница отдаётся из `frontend/templates/mesto_prototype.html`.
- Двойной клик по `index.html` тоже открывает страницу. Подложка карты: по умолчанию приглушённая OpenStreetMap (нужен интернет). Если плитки не грузятся, а также при открытии двойным кликом в Chrome (`file://`, сайт плиток такие запросы блокирует), остаётся ровный бежевый фон, как в ролике. Вручную: добавить к адресу `?map=flat` (ровный фон), `?map=soft` (приглушённая карта) или `?map=osm` (обычная); то же задаёт `window.MESTO_CONFIG.basemap`. Лучше открывать через Live Server. Машинки меняются, когда человек отмечает место; демо-движение для показа включается добавлением `?live` к адресу.

## Где что лежит
Статика (стили и скрипты) лежит в `static/` в корне проекта, страница, шаблон и документы в `frontend/`.
```
static/                          в корне проекта, Django берёт отсюда (STATICFILES_DIRS)
  css/
    core/mesto.css               основные стили
    owner/owner.css              стили блока «Я владелец места»
    map/mesto-map.css            стили карты (Кристина)
    map/spots.css                места-«капсулы», машинки, номера, полоса мест
    core/product.css             бонусы, согласия, подсказка про лимит цены, мобильная панель
  js/
    data/mesto-data.js           демо-данные района: 66 зон, 734 места, объявления (Кристина)
    data/mesto-streets.js        улицы и номера мест: зоны сгруппированы по настоящим улицам района (Яндекс Карты): ROADS в начале файла
    core/                        ядро
      util.js                    мелочи: выбор элементов, форматы, иконки, швы MAP / OWN / API
      state.js                   состояние приложения и расчёты по зонам
      app.js                     вкладки, отрисовка, обработка кликов, окно, подсказка
    api/                         связь с сервером (каждый раздел включается флагом)
      client.js                  общий клиент: запросы, ошибки, CSRF
      zones.js                   зоны и отметки
      rent.js                    аренда и брони
      owner.js                   владелец места
    auth/auth.js                 регистрация, вход, паспорт (всё в одном файле, для Насти)
    features/                    вкладки и блоки
      map/map-view.js            вкладка «Карта»: панель, слои, прогноз, отметки
      map/mesto-map.js           сама карта (Leaflet): капсулы мест, машинки, уехал/приехал
      map/spots.js               полоса мест с номерами, выбор места, отметка «свободно/занято»
      bonus/bonus.js             бонусные баллы за отметки и купоны (пока в браузере, партнёры примерные)
      rent/rent.js               вкладка «Аренда», бронь, договор
      offer/offer.js             вкладка «Сдать»
      account/account.js         вкладка «Аккаунт»
      owner/owner.js             блок «Я владелец места»
      docs/docs.js               соглашение, оферта, политика данных
frontend/
  index.html                     страница для просмотра без Django (подключает ../static/…)
  templates/mesto_prototype.html страница для Django ({% static %})
  docs/API.md                    адреса и поля для бэкенда
  docs/AUTH.md                   памятка по регистрации и входу (для Насти)
```
В `settings.py`: `STATICFILES_DIRS = [BASE_DIR / 'static']`. Порядок подключения скриптов важен, он записан в `index.html` и в шаблоне. Файлы Кристины (`mesto-data.js`, `mesto-map.js`, `mesto-map.css`) лежат в своих папках. В `mesto-map.js` добавлены подключение `spots.js` и выбор подложки.

## Как устроено, чтобы можно было менять по частям
- Карта, блок владельца и связь с сервером это отдельные файлы. Приложение обращается к ним через `MAP`, `OWN` и `API`; если файл не загрузился, остальное работает (на месте карты будет заглушка).
- Модули подключаются к ядру тремя строками: `VIEWS.вкладка = функция` (какую страницу показывать), `act('имя', функция)` (что делать при клике на `data-a="имя"`), `onChange` и `onInput` (поля формы). Чтобы добавить кнопку, достаточно написать `act(...)` в нужном файле.
- Приложение сообщает о действиях событиями `mesto:mark`, `mesto:signup`, `mesto:publish` и т.д., а файлы из `api/` и `auth/` отправляют их на сервер.
- Разделы API включаются по одному флагами в `window.MESTO_CONFIG` в шаблоне (`false` на `true`), пока флаг выключен, раздел работает на демо. Подробности в `docs/API.md`.
- Всё, что вводит пользователь, перед вставкой в страницу проходит через `esc()`.

## Бэкенд (Django)

### Запуск
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py import_spots main/data/spots.geojson
python manage.py seed_fake_data      # ТЕСТОВЫЕ данные (если команда есть)
python manage.py rebuild_stats
python manage.py runserver
```
Сайт: http://127.0.0.1:8000/

### Модели (main/models.py)
- ParkingSpot: парковочное место (code, геометрия, текущий статус)
- SpotObservation: журнал замеров «занято/свободно»
- SpotHourStat: счётчики по месту, дате, дню недели и часу

### API
- GET /api/spots/ : все места в GeoJSON со статусом и «обычно свободно, %»
- POST /api/spots/<code>/status/ : принять {"is_occupied": true/false}
- GET /api/spots/<code>/heatmap/ : матрица «час × день недели»

### Данные
- main/data/spots.geojson: места, оцифрованные по спутнику
- Команды: import_spots (загрузка), rebuild_stats (пересчёт), seed_fake_data (тестовые данные, `--clear` удаляет)
- db.sqlite3 в Git не хранится: после клонирования выполнить команды из раздела «Запуск»
