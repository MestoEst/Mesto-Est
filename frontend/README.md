# Место есть: интерфейс без сборки

HTML, CSS, JavaScript и Leaflet. Обычный запуск — через Django на `/map`.

Карта теперь использует **только места из базы через `/api/spots/`**. Контролируемый набор первоначальной загрузки — `main/data/spots.geojson`: 734 места, 66 зон. Старый спутниковый GeoJSON и генератор RUNS находятся в архиве и не загружаются приложением. Сопоставлять прежние полигоны не нужно.

Полное описание формата, постоянных ID, редактирования мест, localStorage, резервных копий и перехода существующей базы: `../docs/spot-ids/README.md`.

## Новый проект с пустой базой

```sh
python -m venv .venv
# активируйте окружение для своей ОС
pip install -r requirements.txt
python manage.py migrate
python manage.py import_spots main/data/spots.geojson --dry-run
python manage.py import_spots main/data/spots.geojson
python manage.py runserver
```

Для **существующей базы** эти команды не заменяют процедуру перехода: сначала полная резервная копия, миграция схемы, затем отдельный `transition_spots --dry-run` и применение с новой полной копией. Старые записи и история остаются в наборе legacy. Подробные команды находятся в указанной инструкции. Рабочую базу автоматически не сбрасывайте.

Leaflet включён локально в `static/vendor/leaflet/` с лицензией. Внешняя подложка OpenStreetMap требует интернета; `?map=flat` показывает ровный фон. Режим `?live` больше не меняет реальные статусы случайным образом. Неизвестные статусы серые и без машинок.

`frontend/index.html` сохранён как статическая оболочка, но независимой карты без Django API больше нет. При запуске через Live Server или file:// потребуется настроить доступ к API; по умолчанию используйте Django. При ошибке API показывается сообщение и кнопка повторной загрузки.

## Где находится код

- `static/js/data/mesto-data.js`: принимает GeoJSON из API, строит представление зон/мест, отделяет оформление от физических границ. Не генерирует места из RUNS.
- `static/js/api/zones.js`: загрузка канонического набора, сохранение статусов конкретных ID; отдельные обработчики зонных действий.
- `static/js/features/map/mesto-map.js`: Leaflet и выбор полигона.
- `static/js/features/map/spots.js`: машинки, подписи, подсветка, три состояния и счётчики.
- `static/js/features/map/map-view.js`: панель, повтор загрузки и экспорт старой разметки.
- `static/js/features/offer/offer.js`: выбор места для объявления по постоянному ID.
- `frontend/templates/mesto_prototype.html`: Django-шаблон; порядок подключения скриптов важен.
- `frontend/docs/API.md`: действующий контракт мест и проекты дополнительных API.

Связь с другими модулями по-прежнему проходит через MAP, OWN, API и события mesto:*. Существующие функции аккаунта и прочих разделов не переписывались. API зон, объявлений, броней и документов не добавлялся этой задачей; их флаги остаются выключенными, примерные объявления/точки зарядок — демонстрационные.

## Проверки

```sh
python manage.py test main
node tests/spot_ids.test.cjs
python tools/rehearse_spot_ids.py
```

Браузерный тест и запуск отдельной тестовой базы описаны в `../docs/spot-ids/README.md`. Не запускайте браузерный тест против рабочей базы: он записывает статусы.
