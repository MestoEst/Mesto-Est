# Архив отменённого подхода

Материалы из коммита e4e0875 сохранены для истории. Таблица code-map-confirmed.csv, matching-review.json, QUESTIONS.md и review.html не используются для импорта, переноса истории или приёмки текущей реализации. Подтверждать 300 пар больше не нужно.

frontend-baseline.json фиксирует геометрию оформления и явно сохранённые ID прежней карты. Он используется только для проверки точности однократного экспорта геометрии фронтенда, без сопоставления со спутниковым GeoJSON.

Основной набор: main/data/spots.geojson; инструкции: ../README.md.
